# StratoriaLT – fișiere publice

Fișierele pe care pluginul StratoriaLT le citește de pe internet. Toate sunt semnate cu cheia emitentului, iar pluginul refuză orice fișier modificat.

- `versiune.txt`: ultima versiune publicată (comanda ACTUALIZARE / ACT), cu adresa și amprenta SHA-256 a setup-ului.
- `StratoriaLT-Setup-<versiune>.exe`: setup-ul acelei versiuni.
- `revocari.txt`: lista licențelor retrase (verificată o dată pe zi).
